# 🤖 راهنمای اجرای ربات حمله خودکار هوش مصنوعی CoCAI روی گوشی و سرور اندروید

این ماژول به شما اجازه می‌دهد حمله خودکار بازی کلش اف کلنز را مستقیماً روی **گوشی واقعی** یا **سرور شبیه‌ساز اندروید** اجرا کنید.

## روش‌های اجرا:

### روش اول: اجرای مستقیم روی گوشی اندروید (بدون نیاز به کامپیوتر)
1. برنامه **Termux** را از F-Droid یا Google Play روی گوشی نصب کنید.
2. برنامه **Shizuku** را برای دسترسی بدون روت یا دسترسی روت فعال کنید.
3. در ترمینال Termux دستور زیر را اجرا کنید:
   ```bash
   pkg install python -y
   curl -s https://cocai.nabuxai.com/downloads/cocai-android/cocai-android-agent.py -o bot.py
   python bot.py
   ```

---

### روش دوم: اتصال گوشی با کابل USB یا WiFi به کامپیوتر (ADB)
1. در گوشی گزینه **Developer Options (گزینه‌های توسعه‌دهنده)** و سپس **USB Debugging (اشکال‌زدایی USB)** را فعال کنید.
2. گوشی را با کابل به کامپیوتر یا سرور متصل کنید.
3. اسکریپت `cocai-android-agent.py` را اجرا کنید:
   ```bash
   python cocai-android-agent.py
   ```
4. هوش مصنوعی CoCAI صفحه را تحلیل کرده و کلیک‌ها را دقیقاً با میلی‌ثانیه مشخص روی گوشی می‌زند!

---

### روش سوم: اجرا روی سرور ابری اندروید (Cloud Android VPS / Redfinger / LDPlayer)
روی سرور کلود اندرویدی که بازی رویش نصب است، اسکریپت پایتون را اجرا کنید تا بدون دخالت دست اتک‌های وار و فارم را ۳ ستاره کند.
